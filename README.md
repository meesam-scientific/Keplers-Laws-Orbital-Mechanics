# Keplers Laws of Planetary Motion Final Year Project (MTH600)

Hello! I am Meesam Raza. This is my final year project for BS Mathematics from Virtual University of Pakistan.

In this project, I am using Python to show Kepler's laws of planetary motion. Because my major is Math, I wanted to apply math formulas of gravity into computer code to see how orbits work.

### Part 1: Kepler's First Law
The file `keplers_1st_law.py` has the code for the first law (Law of Ellipses). It calculates how a planet moves around the sun day by day using basic Newton's gravity rules. 

I used `matplotlib` to draw the path. You can see the final graph in the picture `keplers_1st_law_plot.png` which shows the elliptical orbit.

I will add the code for the 2nd and 3rd law soon.
